Project: Emergency Help Network for Police, Ambulance and Fire & Rescue Services. University of Ruhuna, Faculty of Engineering; EC5205 Operating Systems & Network Programming; three-member group; 15 marks. The supplied assignment deadline is 14 November 2026.

## Prepared artifacts

- Complete Java source, three-module Maven build, pinned wrapper/dependencies and full versioned SQLite schema.
- Runnable server/client shaded JARs; explicit repeatable fictional seed; console-only UI with academic disclaimer.
- Automated tests with actual results; full separate-process workflow/restart/recovery; 20-session localhost load and measured commit-to-receipt latency.
- Architecture/recovery/state/database diagrams, protocol, feature-to-test traceability, demo/setup/Eclipse/LAN instructions, troubleshooting/limits and actual contribution record.
- Source and runtime ZIPs generated by the package helper under application/.local/submission/. Source excludes Git/local tools/DBs/journals/build output; runtime includes JARs/config/start instructions.

## Group actions before submitting

1. Review code/results and confirm Member 2's branch has been reviewed/merged before merging Member 3. Use each actual author's identity and truthful review/contribution records. No fabricated student names/approvals are supplied.
2. Run the separate-laptop permitted LAN checklist and physical keyboard/Eclipse checks; record actual evidence. These require hardware/context not available to this session.
3. Compare the final files against the lecturer's actual submission format/channel and any additional assignment material. The original lecturer document/LMS instructions were not provided; do not assume a report template, video format or upload procedure from this prototype brief alone.
4. After the final Git commit exists, clone that exact commit cleanly and rerun build/seed/smoke on the intended submission machine. A fresh source-export verification is supplied locally without inventing commits.
5. Regenerate packages after any final changes. Check artifact checksums, source archive exclusions and runtime instructions; keep private/local fictional records out of Git/submission ZIPs.
6. Submit through the lecturer's authorized channel before the actual deadline and retain the submission receipt. No external submission/upload is performed by this session.
